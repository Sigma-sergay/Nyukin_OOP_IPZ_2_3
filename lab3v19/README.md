## Мета роботи
Поглибити розуміння життєвого циклу об’єкта в C#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс `IDisposable` та патерн `Dispose`.

---

## Варіант 19: Клас `EventLogger`

### Завдання:
- **Клас:** `EventLogger` (імітує логування подій у систему)
- **Поля:** `_logName` (string), `_isLogging` (bool — імітація некерованого ресурсу)
- **Метод:** `LogEvent(string eventName)` — записує подію, якщо логування активне
- **Очищення:** зупинка логування та закриття сесії/файлу логування через патерн `Dispose`
