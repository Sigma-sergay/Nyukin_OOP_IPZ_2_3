## Як запускати

Потрібен .NET SDK 8.0.

```bash
# одна робота
cd IndependentWork1
dotnet run

# збірка всіх проєктів (рішення SelfWork.sln)
dotnet build

# тести самостійної №7
dotnet test IndependentWork7.Tests
```

Особливі режими:
- `InvertedIndexDemo`: `dotnet run` (інтерактивний пошук), `dotnet run -c Release -- bench` (вимірювання продуктивності);
- `IndependentWork11` та `IndependentWork12`: для чесних вимірювань запускайте в Release: `dotnet run -c Release`.

## Що перевірити перед здачею

1. **Тести СР7.** Я перевірив логіку 19 тестів через тимчасовий запускач, але пакет xUnit у моєму середовищі встановити не вдалося, тож справжній `dotnet test` запустіть у себе й переконайтеся, що все зелене.
2. **Числа вимірювань (СР10, СР11, СР12).** Їх отримано в контейнері з **одним процесорним ядром**. Для СР12 це принципово (PLINQ не показує виграшу на одному ядрі), тому запустіть програму на своєму комп'ютері та замініть таблицю й коментарі у звіті власними результатами. Для СР10 і СР11 відносні висновки лишаються правильними, але абсолютні цифри будуть іншими.
3. **Посилання на GitHub.** У звітах, де вимагається посилання на репозиторій, підставте своє.
4. **Лінки в СР3 та СР8** ведуть на гілки `master`/`main` відкритих проєктів станом на 22.10.2026; номери рядків можуть зсунутися, тож відкрийте кілька посилань і переконайтеся, що вони працюють.
5. **Скріншоти.** Якщо викладач вимагає скріншот виводу, зробіть його після запуску `dotnet run`.
6. **Самостійні номер 13-20** у цьому архіві відсутні: я мав завдання лише для №1-12.
